\section{Related work}
\label{sec:related}

\subsection{Structured policies and learning from demonstrations}
\label{sec:related-structured}

Since embodied policies can often be naturally expressed in code, many works have explored incorporating LLM code generation into policy representations.
The most direct approaches generate executable policies, symbolic plans, or production rules from language instructions~\citep{liang2022code,liu2023llm+,kirk2024improving}.
Other approaches generate intermediate components that define behavior indirectly, such as spatial value maps and language-guided state abstractions~\citep{huang2023voxposer,peng2024learning,peng2024adaptive}.
More recent graph-based approaches, including Graph-as-Policy (GaP), compose perception, planning, and control modules into interpretable computation graphs~\citep{chen2026gap}.

Demonstration-guided approaches use expert knowledge, narrated actions, or interactive corrections to construct interpretable representations of behavior~\citep{zhu2025sample,kim2025interactiveprogramsynthesismodeling,zhu2026interpret}.
Our representation follows KIM~\citep{zhu2025sample}: generated code specifies a sparse semantic structure, while continuous parameters are learned from demonstrations.
We extend this separation by generating tabular data analysis code to identify misalignment and guide structural updates, reducing the need for human corrective instructions.

Reinforcement learning from demonstrations improves learning efficiency by shaping rewards, augmenting replay data, or initializing policies and dynamics models~\citep{brys2015reinforcement,hester2018deep,uchendu2023jump,hansen2022modem}.
Our work uses demonstrations to fit parameters within successively refined structures, so subsequent reinforcement learning starts with both a learned policy and a demonstration-aligned structure.

\subsection{LLM-guided program revision and execution feedback}
\label{sec:related-refinement}

Classical neural architecture search automates structure design through differentiable, evolutionary, or learned search over model primitives~\citep{liu2018darts,jian2023eenas,zoph2018learning}.
LLM-guided methods instead use semantic knowledge and execution feedback to revise programs directly, including self-debugging, algorithm evolution, and coding-agent improvement~\citep{chen2023selfdebug,novikov2025alphaevolve,zhang2025darwin}.
Related methods revise reward functions or state representations using learning and environment feedback~\citep{ma2023eureka,li2025R,peng2024adaptive}.

In robotics, programmatic search and agentic learning systems use rollout feedback to improve control programs, reusable skills, or the surrounding learning workflow~\citep{hu2025multimodal,lu2026aspire,xiao2026enpire}.
Graph-based refinement extends this process to modular policy graphs, with GaP using simulation rehearsal to improve graph structure and parameters~\citep{chen2026gap}.

Our pipeline uses code generation in two complementary ways: one program defines the trainable policy structure, and another analyzes its tabular rollouts.
The sparse semantic structure connects numerical feedback to specific computations that can be revised, while demonstrations fit the continuous parameters between revisions.
This differs from searching only over complete executable policies or optimizing a reward function: the analysis code inspects the intermediate values of the policy itself to guide structural refinement.
