## Prioritized gaps before prose drafting

1. **Recover one complete refinement iteration.** Required for the reviewer's central clarity issue and the paper's explanatory center. Needed artifacts: before/after programs, demonstration-fitting context, rollout logs, generated tests, results, and post-refit evaluation. If unavailable, use an explicitly schematic explanation and keep measured results separate; do not invent a matched trace.
2. **Recover the actual refinement/training protocol.** Determine initialization versus transfer after edits, fitting termination, refinement stopping/budget, additional-test handling, and whether any candidate-selection rule existed. Use these facts in Sections 4.2/4.5 and Appendices B/C.
3. **Verify evaluation and accounting.** Establish run counts, seeds, uncertainty aggregation, reward definitions, table subsampling, token scope, and refinement versus RL resets. The reported 403 versus 2,000 reset comparison is about 79.9% fewer resets, not measured total-compute savings; reconcile it with the old abstract's percentage.
4. **Create the explanatory material.** Build the loop diagram, sample topology (panel A) in Section 3, illustrated latent traces (panel B) in Section 4.3, diagnostic and edit panels C–D in Sections 4.4–4.5, compact algorithm, and brief debugging analogy. Section 4.2 explains parameter initialization and fitting textually. Keep large raw tables out of the main-text example while retaining the numerical analysis interface. Explain the lack of a complete behavioral oracle and the need to refit after editing; do not imply all diagnostics are binary tests. These are presentation work grounded in existing artifacts, not new empirical claims.
5. **Select and verify citations.** Reuse candidate entries from R's `ijcai26.bib`, with KIM explicitly attributed. Bibliographic verification and import are deferred until drafting; the template's example bibliography is unchanged. Bibliography output is temporarily commented out in `main.tex` so the citation-free outline builds without an empty-bibliography error; re-enable it when adding research citations.

The manuscript does not supply isolated semantic-name/latent-logging ablations, recovery from systematically perturbed initial structures, or broad cross-domain validation. These are limits to state, not assumed experiments to add in the current outline task. If further evidence is later desired, it should be scoped separately.
